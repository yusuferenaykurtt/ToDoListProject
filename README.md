# ToDo List Project ✅

This project is a simple and user-friendly **ASP.NET Core MVC** application that I developed for myself to practice and manage daily tasks.  
It provides a clean and easy-to-use interface for creating, editing, completing, and deleting tasks.  

## Features
- Add new tasks with a title  
- Edit existing tasks  
- Mark tasks as completed / uncompleted (toggle)  
- Delete tasks  
- Displays a clear list of all tasks  

## Technologies
- C# / ASP.NET Core MVC  
- Entity Framework Core (Code First)  
- SQL Server Database  
- Bootstrap for responsive and simple UI  

## User Experience
- Designed with a **very simple and intuitive UI**  
- Easy to navigate and operate, even for non-technical users  
- Built with the purpose of being **practical and user-friendly**  

## Purpose
This project was developed as a personal learning and productivity tool.  
It demonstrates the fundamentals of **CRUD operations, Entity Framework integration, and MVC architecture** in a real-life use case.
